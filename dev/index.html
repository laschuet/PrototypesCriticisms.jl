PrototypesCriticisms.criticisms — Function
criticisms(C, c=1)

Compute the c criticisms of every cluster of the k-means or k-medoids clustering C with the centroid-based method, and return their indices, one vector per cluster.

The criticisms of a cluster are its observations farthest from the cluster center, i.e., with the highest assignment costs, in decreasing order. Ties are broken in favor of the lower index. A cluster with fewer than c observations contributes all of them.

See also prototypes.

PrototypesCriticisms.criticisms — Function
criticisms(x, k, protos, c=1)
criticisms(X, k, protos, c=1)
criticisms(K, protos, c=1)

Compute criticisms of a data set following the MMD-critic method, and return their indices.

The criticisms are the observations other than the prototypes with the largest absolute values of the witness function, in decreasing order of these values. Ties are broken in favor of the lower index.

Arguments

  • x, X, K, k: the data and the kernel function, as in prototypes_criticisms.
  • protos::AbstractVector{Int}: the indices of the prototypes, e.g., as returned by prototypes.
  • c::Int=1: the number of criticisms, with 1 <= c <= n - p for n observations and p distinct prototypes.

See also prototypes, prototypes_criticisms.

PrototypesCriticisms.mmd2 — Function
mmd2(x, k, protos)
mmd2(X, k, protos)
mmd2(K, protos)

Compute the squared maximum mean discrepancy (MMD) between a data set and its prototypes.

The lower the value, the better the prototypes represent the data. It is zero if all observations are prototypes.

Arguments

  • x, X, K, k: the data and the kernel function, as in prototypes_criticisms.
  • protos::AbstractVector{Int}: the indices of the prototypes, e.g., as returned by prototypes.

See also witness.

PrototypesCriticisms.prototypes — Function
prototypes(C, p=1)

Compute the p prototypes of every cluster of the k-means or k-medoids clustering C with the centroid-based method, and return their indices, one vector per cluster.

The prototypes of a cluster are its observations closest to the cluster center, i.e., with the lowest assignment costs. Ties are broken in favor of the lower index. A cluster with fewer than p observations contributes all of them.

See also criticisms.

PrototypesCriticisms.prototypes — Function
prototypes(x, k, p=1)
prototypes(X, k, p=1)
prototypes(K, p=1)

Compute prototypes of a data set following the MMD-critic method, and return their indices.

The prototypes are selected one after another. Every selection minimizes the squared maximum mean discrepancy between the data and the prototypes selected so far, see mmd2. Ties are broken in favor of the lower index.

Arguments

  • x, X, K, k: the data and the kernel function, as in prototypes_criticisms.
  • p::Int=1: the number of prototypes, with 1 <= p <= n for n observations.

See also criticisms, prototypes_criticisms.

PrototypesCriticisms.prototypes_criticisms — Function
prototypes_criticisms(x, k, p=1, c=1)
prototypes_criticisms(X, k, p=1, c=1)
prototypes_criticisms(K, p=1, c=1)

Compute prototypes and criticisms of a data set with the MMD-critic method, and return a tuple of the indices of the prototypes and the indices of the criticisms.

The prototypes are computed with prototypes, and the criticisms are computed with criticisms.

Arguments

  • x::AbstractVector: the observations, e.g., a vector of vectors or a vector of numbers for one-dimensional data.
  • X::AbstractMatrix{<:Real}: the data matrix, with one observation per column.
  • K::AbstractMatrix{<:Real}: the precomputed kernel matrix. Only squareness and symmetry are checked.
  • k::Kernel: the kernel function for computing the kernel matrix of x or X.
  • p::Int=1: the number of prototypes, with 1 <= p <= n for n observations.
  • c::Int=1: the number of criticisms, with 1 <= c <= n - p for n observations and p prototypes.

PrototypesCriticisms.witness — Function
witness(x, k, protos)
witness(X, k, protos)
witness(K, protos)
witness(x, k, protos, z)
witness(X, k, protos, z)

Compute the witness function of a data set and its prototypes, and return its values at all observations, or its value at z if given.

The witness function at an observation is the mean kernel value between the observation and the data minus the mean kernel value between the observation and the prototypes. Positive values indicate that the prototypes underrepresent the data around the observation, and negative values that they overrepresent it.

Arguments

  • x, X, K, k: the data and the kernel function, as in prototypes_criticisms.
  • protos::AbstractVector{Int}: the indices of the prototypes, e.g., as returned by prototypes.
  • z: a single observation, which does not need to be part of the data, e.g., an element of x or a column of X.

See also criticisms, mmd2.
