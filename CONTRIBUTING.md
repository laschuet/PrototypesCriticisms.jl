# Contributor’s Guide

This guide is intended for anyone considering opening an **issue** or **pull request**. If in doubt,
please open a [discussion](https://github.com/laschuet/PrototypesCriticisms.jl/discussions); we can
always convert that to an issue later.

## Quick Guide

**I have a question!**

Open a discussion.

**I have an idea for a feature!**

Open a discussion.

**I have a bug!**

1. Search the issue tracker and discussions for similar issues.
2. If you don't have steps to reproduce, open a discussion.
3. If you have steps to reproduce, open an issue.

**I'd like to contribute!**

Pick an issue and start working on it. If you need help or guidance, feel free to comment on the
issue.

**I've implemented a feature!**

1. If there is an issue for the feature, open a pull request.
2. If there is no issue, open a discussion and link to your branch.
